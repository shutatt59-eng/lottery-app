# ロト予想アプリ

ロト6・ロト7・ミニロトの予想数字をワンタップで作れる、スマホ向けのシンプルなWebアプリです。
HTML / CSS / JavaScriptのみで作られており、特別なインストールは不要です。

## 使い方

1. 上のタブで「ロト6」「ロト7」「ミニロト」から遊びたいくじを選ぶ
2. 「口数」の＋／−で欲しい口数（1〜5口）を選ぶ
3. 「予想数字を作る」を押すと、ランダムな数字が表示される
4. 作った予想は自動で「これまでの予想」に保存される（スマホ・ブラウザ内に保存）

## 動かし方

### すぐに試す
`index.html` をブラウザで直接開くだけで動作します。

### GitHub Pagesで公開する
1. このリポジトリの Settings → Pages を開く
2. Branch を `main`（公開したいブランチ）、フォルダを `/root` に設定して保存
3. 発行されたURLにスマホからアクセス

## ファイル構成

```
index.html      画面の構造
css/style.css   デザイン（配色・レイアウト）
js/script.js    数字の生成・履歴保存などの動作
README.md       このファイル
```

## 注意事項

このアプリが表示する数字はすべて**ランダムに生成**されたものです。
実際の抽せん結果を予測したり、当せんを保証したりするものではありません。
過去の抽せん結果と次回の抽せんに関連はなく、あくまで数字選びの参考・娯楽用としてご利用ください。
